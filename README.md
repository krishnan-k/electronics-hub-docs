# Electronics Hub Theme Documentation

Complete guide to the **Electronics Hub** Shopify theme (version 2.1.0, built on Shopify Horizon) for the store electronics-hub-fartiln5.myshopify.com.

Every page follows the same pattern: a one-line description, **How to access** steps in the Shopify admin, and tables listing each **setting** with what it does. Section pages also list their **blocks**.

Start with [Getting started](general/readme.md), then use the sidebar to open a section, an inner page, or a how-to guide.
