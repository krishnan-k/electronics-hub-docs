# Predictive search

Displays live search suggestions in a modal as customers type.

## How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. **Click** Customize on your active theme.
3. Open **Theme settings** → **Search** for the search modal appearance.
4. Predictive search content is controlled by the sections below.

### Section Settings

This section has no settings of its own. Use its blocks to control the content.

### Blocks

Add blocks to this section in the theme editor. Each block is a separate item you can add, remove, and reorder.

This section accepts **theme blocks** (text, button, image, group, and more). See [Theme blocks](../blocks/theme-blocks.md) for every block and its settings.
