# Predictive search empty state

Displays suggestions inside the search modal before a customer types.

## How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. **Click** Customize on your active theme.
3. Open **Theme settings** → **Search**.
4. Configure the empty state content from the search modal.

### Section Settings

This section has no settings of its own. Use its blocks to control the content.
