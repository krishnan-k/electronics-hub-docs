# Related products

Show similar products below the product page. Shopify chooses them automatically from product data such as collections and tags.

## How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. **Click** Customize on your active theme.
3. Open **Products → Default product**.
4. Select the **Related product** section.

On this store the section is titled **You may also like**, shows up to 4 products in a grid, and is set to **Related**. See [Related product](../sections/product-recommendations.md) for every setting.

{% hint style="info" %}
Automatic recommendations may take a short time to appear for new products or stores with little order history.
{% endhint %}
