# Media with text

Displays a large image or video beside a block of content.

## How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. **Click** Customize on your active theme.
3. Open a page such as **Home page** from the page picker.
4. Click **Add section** and choose **Media with text**, or select an existing Media with text section.

### Section Settings

| Setting | Description |
| ------- | ----------- |
| Media position | Sets the media position. Choose from Left or Right. |
| Media width | Sets the media width. Choose from Narrow, Medium, or Wide. |
| Media height | Sets the media height. Choose from Auto, Small, Medium, Large, or Full screen. |
| Section width | Sets the section width. Choose from Page or Full. |
| Extend media to screen edge | Turn on to extend media to screen edge. |
| Background color | Sets the background color. |
| Padding |  |
| Top | Sets the top padding. Range: 0–100 px. |
| Bottom | Sets the bottom padding. Range: 0–100 px. |

### Blocks

Add blocks to this section in the theme editor. Each block is a separate item you can add, remove, and reorder.

#### Content

Holds the content area beside the media, without its own appearance settings.

| Setting | Description |
| ------- | ----------- |
| Layout |  |
| Alignment | Sets the alignment for layout. Choose from Left, Center, or Right. |
| Position | Sets the position for layout. Choose from Top, Center, Bottom, or Space between. |
| Gap | Sets the gap for layout. Range: 0–100 px. |

#### Media

Holds the media beside the content, without its own appearance settings.

| Setting | Description |
| ------- | ----------- |
| Type | Sets the type. Choose from Image or Video. |
| Image | Selects the image. |
| Link | Sets the link destination. |
| Video | Selects the uploaded video. |
| Loop | Turn on to loop. |
| Autoplay | Enables or disables autoplay. |
| Image position | Sets the image position. Choose from Cover or Contain. |
| Video position | Sets the video position. Choose from Cover or Contain. |
