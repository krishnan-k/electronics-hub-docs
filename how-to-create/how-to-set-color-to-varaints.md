# How to set color to variants

Show colored swatches for the Color option on product pages, product cards, and collection filters.

## How to access

1. **Go to** Shopify Admin → **Products** and open a product.
2. Set the **Product category** (for example Mobile Phones). Categories unlock standard attributes such as Color.
3. Under **Variants**, add an option named **Color** and enter your values (for example Black, Silver, Gold).
4. When Shopify offers to link the option to the **Color** attribute, accept it and choose a value for each color.
5. Click **Save**.

## Defining swatch colors

1. **Go to** Shopify Admin → **Content** → **Metaobjects**.
2. Open the **Color** entries and edit a value to set its **color code** or upload a swatch image.
3. Click **Save**.

## Theme settings that affect swatches

1. **Go to** Online Store → Themes → **Customize** → **Theme settings** → **Swatches**.
2. Check **Variant images**. When on, swatches show the variant's photo instead of the color code.

{% hint style="info" %}
If a swatch looks empty or dashed, the color value has no swatch defined, or **Variant images** is on and that variant has no image. Fix the color value, add a variant image, or turn the setting off.
{% endhint %}

{% hint style="info" %}
Use consistent spelling for color names (for example **Gray**, not both Gray and Grey). The exact menu labels in the Shopify admin may change over time.
{% endhint %}
