# Password footer

Displays the footer of the password page.

## How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. **Click** Customize on your active theme.
3. Use the page picker at the top and open **the matching page**.
4. Select **Password footer** in the sidebar.

### Section Settings

| Setting | Description |
| ------- | ----------- |
| Background color | Sets the background color. |
